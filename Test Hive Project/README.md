# Test Hive - Full Stack Project

This project is an online test platform built with:

- React (frontend)
- Spring Boot (backend)
- MySQL (database)

## 📁 Folders

- `test-hive-react/` → Frontend (React)
- `testhive-backend/` → Backend (Spring Boot)

## 🧑‍💻 How to Run

1. Run the backend:

   - Go to `testhive-backend/`
   - Run: `mvn spring-boot:run`

2. Run the frontend:

   - Go to `test-hive-react/`
   - Run: `npm install`
   - Then: `npm run dev`

3. Open `http://localhost:5173` to view the app
