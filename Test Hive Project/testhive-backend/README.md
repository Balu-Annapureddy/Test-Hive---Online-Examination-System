# Test Hive - Backend (Spring Boot)

This is the backend server for the Test Hive project.

## 🔧 How to Run

1. Open a terminal inside this folder.
2. Make sure you have:
   - Java (version 17 or above)
   - Maven installed
3. Run this command:
   --> mvn spring-boot:run

4. The backend will start at:
   http://localhost:8080

## ⚠️ Notes

- Make sure your database is configured correctly in:
  --> src/main/resources/application.properties

- The frontend should connect to this server on port 8080.
