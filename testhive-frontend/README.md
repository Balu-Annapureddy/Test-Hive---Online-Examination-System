# Test Hive - Frontend (React + Vite)

This is the frontend for the Test Hive project.

## How to Run

1. Open a terminal inside this folder.
2. Run this to install packages:
   ---> npm install

3. Then run this to start the app:
   ---> npm run dev

4. Open your browser and visit:
   http://localhost:5173

## ⚠️ Notes

- Make sure the backend is running at `http://localhost:8080`
- If the app can't connect, check the API URLs in the code.
